# Icon rule

This is an always-on constraint, not a workflow to invoke. Before adding an icon for a stat, a
concept, or a common action, check this file first — reuse the icon already assigned here rather
than picking a plausible-looking one from scratch. Two different icons for the same concept in two
different places is the exact failure mode this file exists to prevent: a coach (or a developer
copying an existing pattern to build something new) should be able to trust that one icon always
means one thing across the whole app.

When you build something new that reuses an existing stat type (a win/loss record, a forced:unforced
ratio, a recent-form strip, and so on), use the icon already assigned to that concept below rather
than choosing your own. When you introduce a genuinely new concept with no entry here, pick an icon
that isn't already claimed by something else in either table, and add a row for it in the same
change — this file only stays trustworthy if every new icon gets logged here at the time it's added,
not retrofitted later.

whether an icon means "go to detail" or "expand this section" from its shape alone.

## Before picking a new icon

1. Check both tables above for the concept you're building. If it's there, use that icon — don't
   introduce a second one because it "feels" more fitting for your specific screen.
2. If the concept is genuinely new, grep `apps/web/src/` for the icon you're about to use (e.g.
   `grep -rn "CircleAlert" apps/web/src`) to confirm nothing else already claims it for a different
   meaning, the same check that caught the collisions this file was written to fix.
3. Add a row to the appropriate table in the same change, so the next person doesn't have to
   rediscover your choice by reading component source.
4. Icon color still follows `.claude/rules/web-color.md` separately — this file governs _which
   shape_, that one governs _which color_. A data icon reinforcing a `SquadRow`-style ranking uses
   its outcome tone class; a structural icon is neutral/muted unless it's a primary action.
